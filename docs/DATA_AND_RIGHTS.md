# Data availability, access and rights

## Intentionally excluded

- Original manuscript images, tiles, ROIs and segmented crops.
- Third-party editorial editions and ETCBC-derived reference tables.
- Raw ground-truth spreadsheets with editorial or expert annotations.
- The sealed Batch 07 transcription packet, the held-out reference transcriptions and any model predictions on it.
- Model weight files and large derived artifacts.
- Private Google Drive folder identifiers, access credentials and account-specific mount state.

The public code does **not** imply permission to redistribute the associated image or reference data. Check upstream licensing, attribution requirements, contractual restrictions and ethical considerations before releasing any research dataset.

## What can be shared now

- Workflow descriptions, computational utilities and redacted code log.
- Aggregate preliminary experiment summary, clearly identified as internal validation.
- A figure redrawn from recorded aggregate numbers (not containing manuscript imagery).
- Empty input templates and synthetic tests.

## Research integrity

The Batch 07 images were checksum-verified, and no reference transcription was included in the prepared expert packet. Later visual inspection of some images occurred during the train–test overlap audit. These events should be reflected in future method sections and evaluated as part of the validation protocol.

## Reuse terms

No software license has been selected yet. The author retains their rights to the original code unless and until a license is added. Rights to third-party imagery and editorial data are separate and cannot be granted by this repository.
